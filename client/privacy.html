Privacy Policy & Data Security

Effective Date: September 14, 2026 • Version 2.4

1. Multi-Tenant Data Isolation & Row-Level Security

Riwaayat Venue is architected as an isolated multi-tenant platform. Every user account, event website, uploaded media, guest list, and RSVP submission is strictly partitioned.

  • Users can only view, edit, and manage their own event websites and data.
  • Database queries enforce server-side Row-Level Security checks using ownerUserId and eventId.
  • Unauthorized cross-tenant access attempts trigger instant 403 Forbidden responses and are flagged in security audit logs.

2. Encryption at Rest for API Keys & Sensitive Integrations

If you configure third-party integration keys (such as Google Maps API or SendGrid keys):

  • All API keys are encrypted at rest using industry-standard AES-256-GCM encryption.
  • Raw keys are never exposed in frontend code, browser local storage, public API responses, or logs.
  • Only masked previews (e.g. sk-••••••••1234) are visible in your private dashboard.
  • You can revoke or delete your integration keys at any moment.

3. Three-Tier Privacy & Selective Sharing Modes

Event creators have full sovereign control over who can view their invitation website:

  • Draft Mode: Strictly inaccessible to anyone other than the authenticated creator.
  • Private Share Mode: Protected behind a secret guest passcode or single-use expiring invite links. Unauthenticated visitors cannot view protected ceremony details, venue addresses, or photos.
  • Public Mode: Publicly viewable, while all administrative settings, guest lists, and RSVP details remain strictly owner-only.

4. Notice Regarding Authorized Recipient Sharing

Important Disclosure: While Riwaayat Venue enforces rigorous access gating, token expiration, and server authorization, no software platform can prevent an authorized recipient from manually taking screenshots or sharing content they have legitimately been granted access to view. We recommend inviting only trusted family and friends for private events.

5. Guest RSVP Data Confidentiality

RSVP responses (including guest phone numbers, meal preferences, and personal blessing messages) are never public and are made accessible strictly to the event host in their private dashboard.
